# 「橙场」赛事卡构图规范

## 统一规则

- 卡片比例：63:88，推荐生成尺寸 1260 × 1760。
- 正面卡面、Logo、姓名、球队和主位置坐标固定。
- 背面完全固定，不区分半身和全身。
- 半身和全身仅改变人物缩放、锚点、移动范围与底部遮挡。
- 统一以眼睛高度为首要对齐基准，避免不同照片的人脸忽高忽低。
- 用户调整后保存 `compositionMode`、`scale`、`offsetX`、`offsetY`，以后所有比赛卡复用。

## 半身构图

适用于胸部、腰部或大腿以上照片。

- 人物中心偏右，中心横坐标约 57.5%。
- 眼睛位于卡片高度约 21.5%。
- 人物最大宽度约 76%。
- 底部从卡片高度约 83.5% 开始渐隐并由前景遮挡。
- 人脸与球衣是主要视觉中心。

## 全身构图

适用于膝盖、小腿以上或完整全身照片。

- 人物中心进一步偏右，中心横坐标约 59.5%。
- 眼睛位于卡片高度约 19.5%。
- 头顶约在 5.5%，脚底约在 95.5%。
- 人物最大宽度约 61%。
- 底部前景只遮挡脚部，保留完整身体动作。

## 自动选择建议

1. 检测到完整脚部或身体纵横比明显偏高：使用全身构图。
2. 图片在胸、腰或大腿处截断：使用半身构图。
3. 无法可靠判断：默认半身构图。
4. 自动布局后，用户仍可切换构图并进行缩放、平移。

## 图层顺序

1. 正面背景
2. 人物背后装饰
3. 人物透明抠图
4. 正面前景遮挡
5. 姓名、球队与主位置
6. Sportlight标识

具体机器可读配置见 `miniprogram/config/card-layouts.js`。
